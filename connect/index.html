Claude · web, desktop and mobile

  1. Open the connector settings

    In Claude, go to Settings → Connectors → Add custom connector.

  2. Paste the server URL
    https://rwbtdokavulbzwhcrmlc.supabase.co/functions/v1/mcp
  3. Open Advanced settings and paste the Client ID
    1755a01c-eb6d-4f6d-a72b-54a0a27bb28c

    Leave OAuth Client Secret blank — there isn't one, and none is needed.

  4. Sign in and approve

    Your browser opens the Boss Your Data sign-in page, then an approval screen. Check it says it will return you to claude.ai, then approve. You only do this once.

Claude Code is not supported yet. Claude on the web, desktop and mobile all work.

ChatGPT · Plus, Pro, Business, Enterprise or Edu

  1. Turn on Developer mode

    Go to Settings → Security and login and switch on Developer mode. On Business and Enterprise an administrator may need to allow this first.

  2. Create the connector

    Go to Settings → Plugins and press the + button. Name it Boss Your Data, then paste this as the MCP server URL:

    https://rwbtdokavulbzwhcrmlc.supabase.co/functions/v1/mcp

    Keep the /mcp on the end — dropping it is the most common mistake.

  3. Choose OAuth and paste the Client ID
    299d0127-55ff-4cf6-853d-d471de7f1f3f

    Leave the client secret blank.

  4. Sign in and approve

    Check the approval screen says it will return you to chatgpt.com, then approve. The tools register automatically.

Developer mode is not available on the ChatGPT free tier. If you cannot find it under Security and login, look at the bottom of the Plugins page — it sits in one place or the other depending on the account.

Codex · CLI, desktop app and IDE extension

  1. Add the server
    codex mcp add boss-your-data --url https://rwbtdokavulbzwhcrmlc.supabase.co/functions/v1/mcp --oauth-client-id c652995e-2f91-4465-9351-5d6945ea7977
  2. Sign in
    codex mcp login boss-your-data

    Your browser opens the Boss Your Data sign-in and approval screens.

If sign-in fails on a redirect mismatch, Codex has bound a random port. Add mcp_oauth_callback_port = 3118 to the top level of ~/.codex/config.toml and ask us to allow that port.

Once you're connected

Start with "What datasets do I have access to?" — then ask anything:

  • Which companies run the most Phase III trials for GLP-1 drugs?
  • Show me FDA warning letters by country over the last three years.
  • Which contract manufacturers make products for our competitors?
  • Build me a dashboard of recent regulatory news for the companies we track.
You will only ever see the datasets on your subscription, and everything is read-only — nothing you or your assistant does can change Boss Your Data's data.
